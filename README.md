# 📄 Insure Landing Page
This project is a modern and responsive landing page for Insure, a fictional, technology-driven life insurance company. The page is designed to present a clear, trustworthy, and user-friendly introduction to their services, emphasizing ease, speed, and the blend of expertise and technology.

![Screenshot of the page](/images/screenshot-1.png)

![Screenshot of the page](/images/screenshot-2.png)

## ✨ Features
- Fully Responsive Design: Provides an optimal viewing experience across all devices, from large desktop screens to mobile phones.

- Interactive Mobile Menu: Includes a JavaScript-powered, accessible navigation menu for mobile users.

- Clean and Professional UI: Presents information about insurance plans in a clear, modern, and visually appealing layout that builds trust.

- Accessibility Focused: The code includes improvements like aria-controls attributes for better screen reader support.

## 🚀 Live Demo
Try the live version here: https://styn1s.github.io/Insure/

## 🛠️ Technologies Used
- HTML5: For semantic and structured page content.

- CSS3: For custom styling, layout, and responsive design.

- JavaScript: For interactive elements, such as the mobile navigation toggle.
